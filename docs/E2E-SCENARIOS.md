# E2E-сценарии: «Календарь звонков»

Документ описывает пользовательские сценарии для end-to-end тестирования. Каждый сценарий
содержит предусловия, пошаговые действия и ожидаемые результаты. Сценарии строятся по
спецификации (§6, §7, §11) и ориентированы на проверку полного пользовательского пути через
интерфейс в браузере.

## Общие правила

- Приложение запущено в прод-режиме: один процесс на `:3000` (API + `frontend/dist`).
- Начальные данные: `meeting-15` и `meeting-30` (§10).
- Таймзона: `Europe/Moscow`. Все даты и время — в этой таймзоне.
- Тестовый браузер: Chromium (Playwright по умолчанию).
- Каждый сценарий независим: предусловия обеспечиваются через API перед запуском шагов.

### E2E-NAV-01. Шапка присутствует на всех экранах

| 1 | Открыть `/` | В шапке: логотип `Calendar`, ссылки «Записаться» и «Админка» |

| 4 | Перейти по логотипу `Calendar` | Открыта главная `/` |

### E2E-NAV-02. Переходы между экранами по ссылкам

**Предусловия:** система запущена с начальными данными.

|-----|----------|---------------------|
| 1 | Открыть `/` | Главная страница |

## Группа 3. Выбор даты и слота

### E2E-SLOT-01. Календарь показывает окно записи 14 дней

**Предусловия:** система с начальными данными.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть `/book/meeting-15` | Календарь: текущий месяц |
| 2 | Проверить даты в календаре | Даты с сегодня по +13 дней кликабельны; под каждой — счётчик «N св.» |
| 3 | Проверить даты за пределами окна | Даты до сегодня (прошлые) и после +13 дня неактивны (приглушены) |

### E2E-SLOT-02. Выбор слота и кнопка «Продолжить»

**Предусловия:** система с начальными данными, текущее время — утро (до 09:00 или раннее).

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть `/book/meeting-15` | Календарь и панель слотов (первый день, все слоты `free`) |
| 2 | Проверить кнопку «Продолжить» | Кнопка неактивна (серая), блок «Выбранное время» показывает «Время не выбрано» |
| 3 | Выбрать слот `09:00 - 09:15` | Слот выделен, в блоке «Выбранное время» показано «09:00 - 09:15» |
| 4 | Нажать «Продолжить» | Показана форма записи (§7.6): сводка, поля ввода, кнопки «Назад» и «Записаться» |

### E2E-SLOT-03. Смена даты обновляет список слотов

**Предусловия:** система с начальными данными.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть `/book/meeting-15` | Сегодняшний день selected, слоты загружены |
| 2 | Выбрать завтрашнюю дату | Список слотов обновлён: все `free`, 36 слотов |
| 3 | Вернуться на сегодня | Слоты обновились: часть может быть `busy` (если есть бронирования) |

### E2E-SLOT-04. День без свободных слотов

**Предусловия:** все слоты на выбранный день заняты (созданы бронирования через API).

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть `/book/meeting-15` | Календарь загружен |
| 2 | Выбрать день, где все слоты заняты | Под датой счётчик «0 св.», панель слотов показывает «На этот день свободных слотов нет» |
| 3 | Проверить кнопку «Продолжить» | Кнопка неактивна |

## Группа 4. Бронирование (happy path)

### E2E-BOOK-01. Успешное бронирование: полный путь

**Предусловия:** система с начальными данными, свободный слот на завтра.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть `/book/meeting-15` | Календарь |
| 2 | Выбрать завтрашнюю дату | Список слотов: все `free` |
| 3 | Выбрать слот `09:00 - 09:15` | Слот выделен |
| 4 | Нажать «Продолжить» | Форма записи: сводка (meeting-15, 15 мин, завтра, 09:00 - 09:15) |
| 5 | Заполнить «Имя»: `Иван Петров` | — |
| 6 | Заполнить «Email»: `ivan@example.com` | — |
| 7 | Заполнить «Заметка»: `Хочу обсудить интеграцию` | — |
| 8 | Нажать «Записаться» | Экран успеха (`/book/meeting-15/success`): тип, дата, время, длительность, имя, email, заметка |
| 9 | Проверить ссылку на каталог | Ссылка «Выбрать другой тип события» → `/book` |

### E2E-BOOK-02. Бронирование без заметки

**Предусловия:** аналогичные E2E-BOOK-01.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1–7 | Шаги 1–7 из E2E-BOOK-01, заметку не заполнять | — |
| 8 | Нажать «Записаться» | Экран успеха: все поля, заметка пуста или отсутствует |

### E2E-BOOK-03. Бронирование становится видимым в админке

**Предусловия:** после успешного бронирования (E2E-BOOK-01).

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть `/admin/bookings` | Бронирование `Иван Петров`, `meeting-15`, завтра 09:00 - 09:15 видно в списке |
| 2 | Проверить колонки | Дата, время начала/конца, длительность, тип события, имя, email, заметка |

### E2E-BOOK-04. Забронированный слот становится busy

**Предусловия:** после успешного бронирования (E2E-BOOK-01).

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|

## Группа 5. Error-сценарии (критичные)

### E2E-ERR-01. Слот занят при отправке формы (409 slot_taken)

**Предусловия:** два браузера/вкладки. Свободный слот `09:00 - 09:15` завтра.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Вкладка A: выбрать слот `09:00 - 09:15`, заполнить форму, НЕ нажимать «Записаться» | Форма готова к отправке |
| 2 | Вкладка B: быстро забронировать тот же слот `09:00 - 09:15` | Бронирование создано (201) |
| 3 | Вкладка A: нажать «Записаться» | Сообщение «Этот слот только что заняли. Выберите другое время» |
| 4 | Проверить поведение | Возврат к выбору слотов, данные обновлены (слот busy) |

### E2E-ERR-02. Валидация формы: пустое имя

**Предусловия:** форма записи открыта (выбран слот).

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Оставить поле «Имя» пустым | — |
| 2 | Заполнить «Email»: `test@example.com` | — |
| 3 | Нажать «Записаться» | Ошибка у поля «Имя»: «Укажите имя, не длиннее 100 символов». Бронь не создана. Данные формы сохранены |

### E2E-ERR-03. Валидация формы: некорректный email

**Предусловия:** форма записи открыта.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Заполнить «Имя»: `Тест` | — |
| 2 | Заполнить «Email»: `ivan` | — |
| 3 | Нажать «Записаться» | Ошибка у поля «Email»: «Некорректный email». Бронь не создана |

### E2E-ERR-04. Попытка бронирования прошедшего времени (422)

**Предусловия:** текущее время после 18:00 (или мок времени).

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть `/book/meeting-15?startAt=...` с `startAt` в прошлом (через URL) | Страница: параметр игнорируется, показывается выбор слота (§7.6) |

### E2E-ERR-05. Несуществующий eventTypeId (404)

**Предусловия:** система запущена.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть `/book/nonexistent-type` | Сообщение «Тип события не найден» и ссылка в каталог `/book` |

## Группа 6. Админ-панель

### E2E-ADM-01. Админ-панель: хаб с переходами

**Предусловия:** система запущена.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть `/admin` | Заголовок «Админ-панель», две карточки-ссылки |
| 2 | Проверить карточки | «Предстоящие встречи» (→ `/admin/bookings`) и «Новый тип события» (→ `/admin/event-types/new`) |
| 3 | Нажать «Предстоящие встречи» | Открыт `/admin/bookings` |
| 4 | Вернуться, нажать «Новый тип события» | Открыт `/admin/event-types/new` |

### E2E-ADM-02. Создание типа события

**Предусловия:** система с начальными данными.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть `/admin/event-types/new` | Форма: `id`, Название, Описание, Длительность, кнопки «Отмена» и «Создать» |
| 2 | Заполнить `id`: `intro-call` | — |
| 3 | Заполнить Название: `Знакомство` | — |
| 4 | Заполнить Описание: `Первый созвон, обсуждаем задачу` | — |
| 5 | Заполнить Длительность: `30` | — |
| 6 | Нажать «Создать» | Перенаправление на `/admin/event-types`, новый тип в списке |
| 7 | Открыть `/book` | `intro-call` появился в каталоге |

### E2E-ADM-03. Дублирование id типа события (409)

**Предусловия:** тип `meeting-15` уже существует.

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть `/admin/event-types/new` | Форма |
| 2 | Заполнить `id`: `meeting-15` | — |
| 3 | Заполнить остальные поля корректно | — |
| 4 | Нажать «Создать» | Ошибка: «Тип события с таким идентификатором уже существует». Форма не очищена |

### E2E-ADM-04. Просмотр предстоящих встреч

**Предусловия:** создано бронирование (E2E-BOOK-01).

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть `/admin/bookings` | Список встреч |
| 2 | Проверить сортировку | Встречи отсортированы по времени начала по возрастанию |
| 3 | Проверить данные встречи | Дата, время, длительность, тип `meeting-15`, имя `Иван Петров`, email, заметка |

### E2E-ADM-05. Предстоящих встреч нет

**Предусловия:** чистая система (нет бронирований).

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть `/admin/bookings` | Сообщение «Предстоящих встреч нет». Не ошибка |

## Группа 7. Интеграция: полный цикл

### E2E-FLOW-01. Полный цикл: создание типа → бронирование → просмотр в админке

**Предусловия:** чистая система (без начальных данных).

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть `/book` | Пустое состояние: «Пока нет типов событий» |

| 3 | Создать тип: `demo`, `Демо-встреча`, описание, 20 мин | Тип создан |
| 4 | Открыть `/book` | Карточка `demo` (20 мин) |
| 5 | Нажать на `demo` | Календарь, все слоты `free` |
| 6 | Выбрать завтрашний день, слот 10:00 - 10:20 | Слот выбран |
| 7 | Заполнить форму: `Алексей`, `alex@example.com` | — |
| 8 | Нажать «Записаться» | Экран успеха: demo, завтра 10:00 - 10:20, 20 мин |
| 9 | Открыть `/admin/bookings` | Встреча `Алексей`, `demo`, завтра 10:00 - 10:20 |
